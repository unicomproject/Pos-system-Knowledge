OneVerz POS — Inventory UI Prototype (29 Screens)
=================================================

Purpose
-------
This package is the UI prototype stage only.
No Flutter implementation, backend implementation, Second Brain update, audit, or lock is included.

How to use
----------
1. Open index.html in a browser to navigate all 29 screens.
2. Root HTML files (01_...html to 29_...html) use the assets/ folder.
3. standalone/ contains the same 29 screens with CSS and product images embedded.
   These files can be pasted/opened directly in an online HTML compiler.
4. reference/ contains the original screenshots from the uploaded ZIP for side-by-side comparison.

Screen groups
-------------
UJ-1: Screens 01-03 — Inventory Dashboard / Current Stock / Product Detail
UJ-2: Screens 04-07 — Opening Stock
UJ-3: Screens 08-14 — Stock Receiving + Serial Number Registry
UJ-4: Screens 15-19 — Stock Adjustment
UJ-5: Screens 20-29 — Channel Stock Allocation

Important
---------
The UI is built with HTML elements/cards/forms/tables/steppers, not by using the screenshots as page backgrounds.
Product photography is extracted from the supplied reference screenshots as image assets.
