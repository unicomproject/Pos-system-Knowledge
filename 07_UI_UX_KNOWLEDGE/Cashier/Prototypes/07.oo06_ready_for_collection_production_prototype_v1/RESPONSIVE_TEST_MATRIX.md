# OO-06 Responsive Test Matrix

| Device class | Suggested viewport | Expected layout |
|---|---:|---|
| Large Desktop | 1600 × 1000 | Full two-column |
| Desktop | 1280 × 800 | Compact two-column |
| Tablet Landscape | 1024 × 768 | Compact two-column |
| Tablet Portrait | 800 × 1280 | Single main column |
| Phone | 390 × 844 | Fully stacked |
| Small Phone | 360 × 800 | Compact stacked |

## Mandatory checks

- No page-level horizontal overflow
- Header and bottom navigation remain reachable
- Long order/customer/store values wrap safely
- Success state remains visible
- Notify CTA remains reachable
- Print / Share controls remain reachable
- Order summary remains readable
- Notification error does not remove Ready state
- Permission/entitlement states preserve shell
- QA panel remains scrollable on phone
