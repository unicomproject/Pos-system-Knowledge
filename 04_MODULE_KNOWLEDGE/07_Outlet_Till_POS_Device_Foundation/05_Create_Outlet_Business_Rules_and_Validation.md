# 05 Create Outlet Business Rules and Validation

> Last Verified Date: 2026-08-06
> Source basis: Unified-Commerce `OutletRequestValidator.cs`

## 1. Field-Level Validation Rules

### 1.1 Step 1: Outlet Details

#### A. Outlet Name
- **Requirement**: Required.
- **Rules**: Trim spaces. Reject whitespace-only input.
- **Length**: 2 to 200 characters.

#### B. Outlet Code
- **Requirement**: Required.
- **Format**: Auto-generated by backend, read-only in UI.
- **Rule**: Must be unique within the tenant (enforced by `uq_outlets_tenant_id_outlet_code` unique index).
- **Format Schema**: `OUT-YYYY-NNNN` (e.g. `OUT-2025-0005`).

#### C. Outlet Type
- **Requirement**: Required.
- **Allowed Values**: `STORE`, `WAREHOUSE`.
- **UI Labels**: Store, Warehouse.

#### D. Status
- **Requirement**: Required.
- **Allowed Values**: `ACTIVE`, `INACTIVE`.
- **Relationship Rule**: An inactive outlet cannot be configured as the Main / Central Outlet or Default for New Tills.

#### E. Outlet Manager
- **Requirement**: Optional in database schema.
- **Selector Rules**: User must be active and scoped to the active tenant. Exclude cross-tenant and suspended accounts.
- **Access Rule**: Assigning a manager does not grant outlet access automatically. Actual access roles must be created under `outlet_user_roles`.

#### F. Outlet Phone & Outlet Email
- **Requirement**: Optional.
- **Phone**: Basic numeric/plus format validation. Length < 40 characters.
- **Email**: Normal email format validation. Length < 255 characters.

#### G. Timezone
- **Requirement**: Required.
- **Allowed Values**: Valid IANA timezone ID (e.g. `America/New_York`).
- **Default**: Preselects tenant's default timezone.

#### H. Main / Central Outlet Toggle
- **Relationship Rule**: Only one central outlet is allowed per tenant. Enabling this toggle for an outlet prompts a confirmation dialog to swap the central designation from the previous outlet.
- **Database Column**: `outlets.is_central_outlet`.

#### I. Default for New Tills Toggle
- **Relationship Rule**: Only one default till outlet is allowed per tenant. The outlet must be in the `ACTIVE` status.

## 2. Step 2: Location and Contact

### 2.1 Address Fields
- **Address Line 1**: Required, max 250 characters.
- **City**: Required, max 120 characters.
- **Country**: Required, two-character ISO country code.
- **Postal Code / State**: Country-dependent validation logic.

### 2.2 Operational Contact
- **Contact Person**: Optional, max 150 characters.
- **Contact Phone**: Optional, max 40 characters.
- **Contact Email**: Optional. Mapped to `outlet_addresses.email`.

### 2.3 Outlet Image upload
- **Supported Formats**: JPG, JPEG, PNG.
- **Size constraint**: Max 2 MB.
- **MIME Verification**: Server-side MIME validation of actual file headers.

## 3. Step 3: Business Hours and Schedules

### 3.1 Regular Weekly Hours
- Days: Monday through Sunday.
- **Status**: Open, Closed, or 24 Hours.
- **Validation**:
  - `Open` status requires both opening and closing times.
  - `Closed` disables all times.
  - `24 Hours` overrides time pickers.
  - Closing time earlier than opening time requires enabling `Overnight` (Spans Next Day) to be valid.

### 3.2 Special Days / Holidays
- **Required Fields**: Date, Holiday Name, Status.
- **Constraints**:
  - Date must be unique per outlet.
  - Special day overrides weekday hours for that specific date.
