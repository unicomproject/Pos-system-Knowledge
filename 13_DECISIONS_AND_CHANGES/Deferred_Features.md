# Deferred Features

## Current Release Cashier Discount

- Manager approval, manager PIN, approval screen, and `PENDING_APPROVAL` wait flow.
- Predefined `POLICY` selection in the cashier popup.
- Item/Line Fixed Amount.
- Multiple or stacked cashier discounts.

Underlying approval endpoint/permission/fields, POLICY support, line-fixed
envelope, and `is_stackable` schema are not removed. They are existing/reserved
capability and must not be presented as current cashier behavior. Authority:
[[POS_CASHIER_DISCOUNT_CURRENT_RELEASE_DECISION_2026-08-09]].
